Nest Logger

Nest Logger is a personal-use Google Apps Script run by David Noyes. It reads the current temperature, humidity and settings of David's own Google Nest thermostat through Google's Smart Device Management API and records them in his own Google Sheet. It is not offered to, or used by, anyone else.

Privacy policy

  • Data accessed: thermostat readings and settings (temperature, humidity, mode, setpoints, HVAC and connectivity status) from the account owner's own Nest device. No camera, doorbell or other device data is used.
  • How it's used: readings are written to a private Google Sheet owned by the account holder, to track home temperature over time.
  • Sharing: data is not sold, shared, or transferred to any third party.
  • Storage: data stays in the owner's Google account. Authorization tokens are stored in the script's private properties.
  • Revoking access: access can be removed at any time from Google Account permissions or the Nest app's Works with Google settings.

Google API data use complies with the Google API Services User Data Policy, including the Limited Use requirements.
